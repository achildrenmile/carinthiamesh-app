# carinthiamesh-app

MeshCore-Client von CarinthiaMesh – browserbasierte PWA (Web Bluetooth).

**Status: Phase 0 (Spike).** Siehe [docs/spike-ergebnis.md](docs/spike-ergebnis.md) und
[docs/ADR-001-protokoll-lib.md](docs/ADR-001-protokoll-lib.md). Screenshots folgen mit Phase 1.

```bash
npm install
npm run dev     # Spike-Seite auf http://localhost:5173 (Chrome/Edge)
npm test        # Protokoll-Tests (Vitest)
```
